# Feature logs

This index is the starting point for concise, dated records of user-visible
changes. Use `YYYY-MM-DD-feature-slug.md` for a small update or a feature
subfolder with dated entries for work that will continue to grow.

Each entry records the root project version, date, one change type
(**Added**, **Modified**, **Improved**, or **Fixed**), and a short outcome.
Do not increment the project version for a log entry. Link to existing guides
instead of repeating their implementation details.
