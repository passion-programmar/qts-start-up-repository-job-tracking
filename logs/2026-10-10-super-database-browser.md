# Super database browser

- **Version:** 1.2.0
- **Date:** 2026-10-10
- **Change type:** Added

## Changes

- Added a Super-only browser for allowlisted new-schema tables with search,
  pagination, and schema-aware record editing.
- Excluded password hashes and migration internals from browsing, and showed
  metadata rather than binary resume or document contents.
- Documented the browser's scope and data protections in
  [the current system guide](../docs/CURRENT-SYSTEM.md).
